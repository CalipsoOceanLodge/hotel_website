# Calipso Ocean Lodge

Official website for **Calipso Ocean Lodge**, a small eco-friendly jungle lodge in Playa Avellanas, Guanacaste, Costa Rica.

## Website

https://calipsooceanlodge.com/

## About

Calipso Ocean Lodge is a six-room jungle lodge located within walking distance of Avellanas Beach.

The property features:

* Six guest rooms
* Swimming pool
* Pool bar
* Tropical garden
* Yoga deck
* Outdoor shared kitchen
* Gated secure parking
* Easy access to Avellanas Beach, local restaurants, and bars

## Website

Built as a lightweight static website using:

* HTML
* CSS
* JavaScript
* GitHub Pages

* `index.html` - Main website
* `style.css` - Website styling
* `script.js` - Interactive functionality
* `images/` - Website images
